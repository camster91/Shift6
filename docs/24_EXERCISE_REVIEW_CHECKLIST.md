# SHIFT6 — Exercise Review Checklist

Use this checklist for each exercise proposed for public release. Completing it is human review evidence; it is not intended to be auto-filled from generated content.

## Identity and taxonomy

- [ ] Exercise name and aliases clearly identify one movement.
- [ ] Movement pattern is appropriate.
- [ ] Primary and secondary muscle labels are reasonable.
- [ ] Equipment requirements are complete and do not imply unavailable equipment.
- [ ] Difficulty and tracking type are appropriate.
- [ ] Bilateral/unilateral classification is correct.

## Technique content

- [ ] Setup instructions describe a usable starting position.
- [ ] Instructions are specific to this movement rather than generic template copy.
- [ ] Technique cues are practical and do not promise injury prevention.
- [ ] Common mistakes are exercise-specific and useful.
- [ ] Range-of-motion language allows appropriate individual variation where relevant.

## Safety and claims

- [ ] Safety notes identify material exercise-specific cautions where appropriate.
- [ ] Content does not diagnose conditions or provide individualized medical treatment advice.
- [ ] Content does not tell a user to train through sharp pain or concerning symptoms.
- [ ] Regressions/progressions do not imply that one variation is universally safe or appropriate.

## Media

- [ ] Any attached image/video depicts the intended exercise.
- [ ] Demonstrated technique is acceptable for the intended instruction.
- [ ] Alt text identifies the useful visual information.
- [ ] Media provenance/licensing is documented outside the user-facing copy where required.
- [ ] Each media item is independently marked approved; exercise review does not auto-approve media.

## Provenance

- [ ] Reviewer identity/role is recorded in `reviewedBy`.
- [ ] Review completion time is recorded in `reviewedAt`.
- [ ] `contentStatus` changes to `reviewed` only after all required review items are complete.
- [ ] Any material later edit to technique or safety instructions is routed through re-review.

## Final publication check

- [ ] `assessExerciseContent()` reports `readyForPublication: true`.
- [ ] The exercise is not retired.
- [ ] No attached media remains unapproved.
- [ ] The exercise is referenced only by stable IDs in public program versions and history.
